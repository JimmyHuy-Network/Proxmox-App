# Proxmox VE Manager 0.2.3

## Bảo mật và sửa lỗi

- Xác minh fingerprint TLS trước khi gửi credential cho REST, console và truyền file.
- Download kiểm tra fingerprint đã ghim; chặn yêu cầu đọc/ghi đường dẫn local do renderer truyền trực tiếp.
- Tách vault E2E khỏi vault thông thường, giới hạn mock ở HTTPS loopback và tắt hook trong bản đóng gói.
- Sửa cache tài nguyên bỏ sót thay đổi dung lượng đĩa và lỗi download file nhỏ thành file rỗng.
- Cập nhật dependency, gồm Electron 43.8.1 và Vite 7.3.7.

## Build và cập nhật

- Build installer Windows x64 (NSIS) trên runner Linux self-hosted bằng Wine và Xvfb.
- Tự chuẩn bị công cụ build trên Debian/Ubuntu khi runner có quyền root hoặc sudo không cần mật khẩu.
- Cải thiện upload artifact và kiểm tra đầy đủ installer, blockmap, `latest.yml` trước khi publish.
- Nguồn phát hành và auto-update: `JimmyHuy-Network/Proxmox-App`.

Installer **chưa ký số**; Windows SmartScreen có thể hiển thị cảnh báo.
Yêu cầu môi trường phát triển: Node.js >= 22.19.
